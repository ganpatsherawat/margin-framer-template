HOME / STYLE GUIDE

Make it yours.

Everything on the site comes from a handful of styles, four CMS collections and a few components. Change them and every page follows.

01

Site settings and the Header / Footer

Name, email, phone and navigation live in siteSettings and the Layout template. Edit them in the Sanity CMS schema or siteData file; every page follows immediately.

02

Color Palettes & Design Tokens

Cobalt, Mint, Lime, and Violet are fully tokenized. Switching the data-palette attribute updates --accent, --accent-light, --accent-dark, and --accent-tint across all highlights, badges, and buttons.

03

Typography System

Fraunces Variable for expressive editorial display headings; Geist for crisp user interface and body copy; Geist Mono for metadata, badges, and numerical statistics; Instrument Serif for italic emphasis.

04

Sanity CMS Schemas

Includes production schemas for Services, Case Studies, Testimonials, Decision Records, and Global Site Settings with structured fields and image hotspots.

05

Decision Record & Strike-Through

The Not-Now list uses a hardware-accelerated CSS transition drawing an inline strikethrough over 0.55s with cubic-bezier(0.65, 0, 0.35, 1) upon scroll viewport entry.

06

Expanding Service Row Hover

Service rows expand a thumbnail image smoothly from width 0 to 78px with cubic-bezier(0.16, 1, 0.3, 1) and rotate the arrow button while highlighting the title.
